# k1llshawty.exe
Закрытый мессенджер по инвайтам. Сквозного шифрования нет: доступ разграничен через RLS.
Порядок установки — в чате; кратко: SQL → настройки Auth → функция register → инвайты → src/config.ts → загрузка на GitHub.
Инвайты (нужен Node.js): `npm run invites -- 5`. Сброс пароля: Supabase → Authentication → Users.
